🍽️ Restro - Restaurant Landing Page Design

A modern, responsive, and aesthetically pleasing restaurant landing page UI built using pure HTML5 and CSS3, enhanced with Font Awesome icons. This project showcases structured web elements, transparent overlays, Flexbox layout design, and continuous CSS keyframe animations.

📌 Project Overview

Restro is a sleek front-end landing page template designed specifically for food, dining, and restaurant services. It features a hero background banner with a dark tint overlay for improved readability, an interactive top navigation menu, engaging call-to-action (CTA) elements, and a rotating dish showcase.

This project was built to practice core Web Development principles, including HTML5 semantic structure, CSS layout mechanics (Flexbox), absolute positioning, and dynamic keyframe animations—without relying on heavy modern JavaScript frameworks.

✨ Features



🎨 Modern UI & Dark Overlay Hero: Fullscreen hero header (100vh) with a semi-transparent dark overlay for high contrast and modern visuals.

🧭 Navigation Header: Clean navigation bar with responsive alignment and custom styling for active/action menu items.

🌀 Rotating Dish Animation: Smooth continuous 360-degree rotation animation (@keyframes) applied to the featured dish image.

📐 Flexbox Alignment: Responsive flex alignment (justify-content: space-around, align-items: center) dividing content into structured sections.

🎯 Customized CTA Button: Uniquely shaped "Book Table" Call-To-Action button utilizing asymmetric border-radius.

🏷️ Font Awesome Icons: Integrated icon support for intuitive visual cues across the top navigation list.

🚀 Getting Started
